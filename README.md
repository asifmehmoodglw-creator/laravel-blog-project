# Laravel Blog Project

A feature-rich blogging platform built with Laravel 8 and PHP 8.

## 🚀 Key Features
* User Authentication & Role-based Access Control
* Dynamic Blog Post Creation & Category Management
* Image Thumbnail Uploads & File Storage
* Interactive Comment System & Star Ratings
* Mailchimp API Integration for Newsletter Subscriptions

## 🛠️ Tech Stack & Environment
* **Framework:** Laravel v8.33.1
* **PHP Version:** v8.0.0
* **Dependency Manager:** Composer v2.9.4
* **Environment:** Laragon (Local Development)
